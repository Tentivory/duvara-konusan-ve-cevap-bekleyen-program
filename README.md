# Duvara Konuşan ve Cevap Bekleyen Program

## Giriş

Bu proje, insanlık tarihinin en derin iletişim problemine çözüm üretmek amacıyla başlatılmıştır: **Duvarlarla konuşmak**.

Herkes bilir ki duvarlar mükemmel dinleyicilerdir. Hiç söz kesmezler. Hiç "hımm" demezler. Hiç "anladım" demezler. Sadece... dururlar. Bu program, o sessizliği bir şaheser haline getirir.

## Özellikler

- **Gerçek zamanlı duvar iletişimi**: Program duvara konuşur. Duvar cevap vermez. Bu bir bug değildir, feature'dır.
- **Varoluşsal kriz modu**: Her çalıştırmada hayatın anlamı sorgulanır.
- **Sonsuz bekleme garantisi**: Duvar asla cevap vermez. Program asla pes etmez.
- **Bilimsel altyapı**: Rastgele seçilen itiraflar + time.sleep() = felsefe.

## Kurulum

```bash
git clone https://github.com/Tentivory/duvara-konusan-ve-cevap-bekleyen-program
cd duvara-konusan-ve-cevap-bekleyen-program
python3 duvar.py
```

> Uyarı: Bu programı çalıştırırken gerçek bir duvarın karşısında durmanız tavsiye edilir. Aksi takdirde programın etkinliği %0.0001 azalabilir (veya artabilir, bilinmiyor).

## Nasıl Çalışır?

1. Program duvara bir itirafta bulunur.
2. Duvar cevap vermez.
3. Program bekler.
4. Duvar hala cevap vermez.
5. Program bu durumu kabul eder ve devam eder.
6. Tekrar.

Bu döngü, insanın iç dünyasının mükemmel bir simülasyonudur.

## Katkıda Bulunma

Pull request açabilirsiniz ama duvar kabul etmeyebilir. Duvar çok seçicidir.

## Lisans

Bu proje "Duvar Lisansı" altındadır. İstediğiniz gibi kullanabilirsiniz, duvar izin verirse.
